Runner infinito en el navegador. Sin dependencias.

**Jugar:** https://71x7.github.io/FoxRun/

## Ejecutar en local

```bash
unzip FoxRun.zip
cd FoxRun
python3 -m http.server 8000
```

Abrir `http://localhost:8000`.

## Publicar

Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.

## Controles

- Espacio / ↑: saltar
- ↓: agacharse
- M: sonido
- Móvil: toque o botones en pantalla
